# מנהל שרתים (VPS) — אפליקציית אנדרואיד בעברית

אפליקציית SSH לניהול שרתי VPS, בעברית מלאה ובעיצוב זכוכית בהשפעת iOS.

## מה יש בה

- **חיבור יציב** — keep-alive כל 20 שניות, זיהוי נפילה מיידי וחיבור מחדש אוטומטי עם השהיה מתגברת.
- **החלפת רשת לא מפילה** — מאזין לשינויי רשת (Wi-Fi ↔ סלולרי), מתחבר מחדש וחוזר לאותה תיקייה שבה הייתם.
- **שירות קדמי** — החיבורים נשארים חיים גם כשיוצאים מהאפליקציה או מכבים את המסך.
- **בלוקים לכל פקודה** — לכל פקודה יש כרטיס משלה עם הפלט, קוד היציאה ומשך הריצה.
- **העתקה בלחיצה אחת** — העתקת כל הפלט של הפקודה, הפקודה בלבד, פקודה + פלט, 20 השורות האחרונות, או כל המסוף.
- **חיפוש** — חיפוש בכל המסוף (עם הדגשת תוצאות וסינון פקודות), וחיפוש בתוך פלט של פקודה אחת לפי שורות, כולל העתקת שורה או כל התוצאות.
- **שמירה מוצפנת** — פרטי השרתים נשמרים מוצפנים על המכשיר בלבד (EncryptedFile), כולל אימות מפתח השרת.
- **סיסמה או מפתח SSH**, פקודת פתיחה אוטומטית, היסטוריית פקודות וכפתור עצירה (Ctrl+C).

## בנייה

הבנייה רצה אוטומטית ב-GitHub Actions בכל דחיפה ל-`main`.
את קובץ ה-APK מורידים מהלשונית **Actions** → הריצה האחרונה → **vps-manager-apk**.

בנייה מקומית: `gradle assembleDebug` (Java 17, Android SDK 35).
